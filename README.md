# Research Atlas

Cornell EMI research workspace with interactive trends, comparisons, coverage, descriptive questions and a source library. Data become visible after entering the shared password.

This public repository contains the static interface and protected payloads. Original datasets, full backend, methods and complete source history remain in the private EMI Observatory repository. No password or API credentials are tracked here.

GitHub Pages serves the browser application. It does not host the Python/FastAPI service. The current visualization covers six annual World Bank indicators; the library catalogs 164 available source and methodology assets. This is not a complete numerical reconstruction of the annual report.

Publication updates are promoted from the private project. Automatic synchronization is not yet active.

Author code: MIT. Plotly.js and IBM Plex license notices are included in vendor/. Source-data rights remain with their respective providers.

Internal prototype prepared for Cornell EMI review, not an official Cornell University publication.
